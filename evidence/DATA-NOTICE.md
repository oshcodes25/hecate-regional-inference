The MIT code license does not relicense CT data or derived scan visualizations. The Vesuvius data portal specifies CC BY-NC 4.0 unless an individual asset says otherwise: https://scrollprize.org/data and https://creativecommons.org/licenses/by-nc/4.0/ . Source records identify the three supplied surface volumes (PHerc0841, PHerc0009B and PHerc0500P2), meshes, scan spacings, native crop positions and deterministic resampling. Original and derived arrays are clearly distinguished.

Dataset: Angelotti et al., *Vesuvius Challenge — CT Scans of Herculaneum Papyri*. These are newer Vesuvius releases, not a claim of authorship of the scans. Preparation: original surface volumes were sampled into bounded native crops and resampled to 2.4 µm by voxel-overlap averaging/rounding. The coarse software tests additionally average 4×4×4 blocks. Predictions were generated by the unchanged released Hecate model and then regionally blended. The scan pixels and predictions are not generated illustrations.

Upstream Hecate code and checkpoints: Vesuvius Challenge, model repository https://huggingface.co/scrollprize/hecate, revision 9cb86e500e944b11a06a7020403cde5dffb5bcb2, MIT. The original code license is preserved in licenses/HECATE-MIT.txt. Checkpoints are omitted from this package and must be obtained from their source to rerun inference.

Prior algorithmic work: villa PR #1247 (TAUIL-Abd-Elilah); existing Hecate 2D optimization by ArcheyChen; existing paired 2D/3D feature proposal in Hecate discussion #1. These contributions are not attributed to the package author.

This edition includes the already qualified PHerc0841 CT input and its completed repeated-inference comparison. Its source coordinates, preparation and checksum are in evidence/qualified-source-inputs.json, evidence/qualified-input-preparation.json and repeatability/registered-plan.json. The new PHerc0841 inference results are in repeatability/outputs/case-02; they establish software equivalence, not newly verified ink. The original E079 results use only PHerc0009B and PHerc0500P2.
