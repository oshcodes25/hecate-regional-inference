Read a small region.
Keep the full context.

Researchers often need to inspect just one part of a scan. Our software gives that region the same surrounding evidence as the larger analysis, while skipping work that cannot affect it.

A CT scan measures the material inside the scroll. Hecate is an existing model that turns scan data into predicted ink scores. We added a way to request a smaller output reliably. This demonstration shows saved measurements; it does not run a model in your browser.

What a researcher can use this for

Inspect a suspect stroke

Keep the original source scan and ask for the small output area you want. The software selects the contributing windows and blends only that output region. This avoids changing the answer just because you chose a smaller input file.

Useful candidates include local annotation checks and interactive inspection. We have demonstrated the API and command line; integration into a community viewer and saved annotation time remain to be tested.

Know when it will help

The biggest opportunity is a small request inside a larger field. Large requests can need every window, and a larger batch can pull in extra windows. This does not make every full-scroll read faster.

In these two examples, temporary blending arrays shrink from 1.70–2.00 MiB to 32 KiB. The model itself still needs substantial memory; the figure is not a reduction in total RAM.

The important competing method

A knowledgeable user can crop a larger, carefully aligned context around the desired output and run the original Hecate. That may obtain the same reduction in model work. Our next benchmark explicitly compares this alternative. The remaining added value may be automatic selection, original batch handling and smaller output accumulators.

The principle of preserving the global tile grid already appears in villa PR #1247. We credit that predecessor and the existing Hecate optimizations. We are not claiming to have invented context preservation.

Check the evidence yourself

1. Check the saved results

Unzip the package, open a terminal in its folder, and run:

python3 verify.py

No installation, model weights or internet connection is needed. Python 3.10+ checks the file hashes and every saved regional value against the matching full-field value. A passing check verifies saved outputs; it does not rerun the model or verify ink truth.

Open all 8 casesRead the instructions

2. Rerun the actual model

Install the pinned dependencies and obtain the hash-checked Hecate checkpoint using the README, then run:

python reproduce.py --rerun --case 0 \
  --models models --output my-rerun

Weights are about 523 MB per resolution. The rerun performs fresh inference and checks its output. Timings depend on the machine. The guide distinguishes this step from the quick saved-result check.

Reproducibility completed so far

The original registered experiment includes two existing physical CT fields, 2.4 and 9.6 µm inputs, 2D and 3D output, both depth directions and batch sizes 1 and 3. All saved regional values agree exactly with their references. A new virtual environment installed 11 pinned packages from hashed wheels, passed the dependency check and all 10 portable software tests, and independently verified the saved results. A fresh installation on the same laptop is not a second-machine replication.

The package retains inputs, outputs, source code, tests, model hashes, source revisions, the original plan, measurements and licenses. All work remains private.

Next measurement is registered, not completed. Three balanced repeats will compare full-field, regional and carefully aligned context-crop inference. The plan includes two fine-resolution examples and edge, centre and large requests on three coarse-resolution specimens. It is waiting for AC power; no new timing or accuracy result is being claimed.
